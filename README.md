# Scenic Stroll

Community-sourced walking routes for Hong Kong: the mall corridors, footbridges, lifts and covered walkways
that standard map apps miss. Users record a route, describe it in their own words (English / 粵語), AI turns
the description into tags (sheltered, step-free, lift…), and others search and follow those routes.

Hackathon prototype · demo area: CityU, Kowloon Tong MTR, Festival Walk.
